# Smart Job Portal System
A full-stack web application that allows users to register, login, view job listings, and apply for jobs. 
This project demonstrates authentication, database integration, and dynamic UI rendering.

# Features
-User Registration & Login (JWT Authentication)
-Profile Access (Protected Route)
-View Available Jobs
-Apply for Jobs
-View Applied Jobs (User Dashboard)
-Add Jobs (Recruiter Feature)
-Clean & Responsive UI

# Tech Stack
Frontend:
-HTML
-CSS
-JavaScript

Backend:
-Node.js
-Express.js

Database:
-MySQL (XAMPP)

Authentication:
-JSON Web Token (JWT)
-Bcrypt (Password Hashing)
